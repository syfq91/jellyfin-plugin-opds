Expose comic book archives (cbz, cbr, cb7, cbt, zip, rar, 7z, tar) and PDF documents page by page to OPDS clients that support the page streaming extension, e.g. Panels.
Expose and accept reading position updates for books via the OPDS progression specification, for OPDS clients that support it. This synchronizes reading position with the rest of Jellyfin, including formats that cannot be streamed page by page such as EPUB.
