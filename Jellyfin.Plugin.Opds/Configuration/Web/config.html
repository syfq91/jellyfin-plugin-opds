Expose comic book archives (cbz, cbr, cb7, cbt, zip, rar, 7z, tar) and PDF documents page by page to OPDS clients that support the page streaming extension, e.g. Panels.
Expose and accept reading position updates for books via the OPDS progression specification, for OPDS clients that support it. This synchronizes reading position with the rest of Jellyfin, including formats that cannot be streamed page by page such as EPUB.
Offer a separate OPDS catalog (/opds/optimized) with the same browsing categories as the main catalog, where EPUB downloads are repacked with oversized images downscaled on first download. The original files are left untouched.
The number of book entries returned per page in OPDS feeds (default: 50).
The maximum width in pixels for downscaled cover thumbnails served to OPDS readers (default: 240).
The maximum length in pixels for the long edge of images in optimized EPUB downloads (default: 1600). Images larger than this are downscaled proportionally.
Encoding quality for downscaled images, from 1 to 89 (default: 82). Values of 90 or above are rejected by the server because they disable image resizing.
How long valid basic authentication credentials are cached in memory to speed up concurrent cover loading (default: 10).
